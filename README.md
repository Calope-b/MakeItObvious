# MakeItObvious
IA métier : à partir d'un support de cours (texte/PDF), le système génère automatiquement des questions adaptées (QCM, vrai/faux), calibrées en difficulté, avec explications en cas d'erreur. Intérêt : évaluations formatives sans effort manuel, adaptées au contenu réel du cours, pas à une banque figée.
